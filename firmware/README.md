# ESP32 Firmware

This folder contains the ESP32 firmware used by PackPilot.

## Hardware

- ESP32-S3
- DHT22 Temperature/Humidity Sensor
- Digital Vibration Sensor
- IR Proximity Sensor

## Communication

- Wi-Fi
- MQTT

## Published Topics

- packpilot/machine/1/temperature
- packpilot/machine/1/vibration
- packpilot/machine/1/ir

## Publish Interval

Every 2 seconds.
